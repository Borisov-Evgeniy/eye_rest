# Eye Rest Timer 🧠👀

Приложение для управления рабочими сессиями и напоминаний о перерывах для снижения нагрузки на глаза при работе за компьютером.

## 📌 Основные возможности

- Таймер рабочих сессий
- Автоматические напоминания о перерывах
- Окно перерыва (overlay / popup)
- Управление через hotkeys
- Возможность остановки и перезапуска таймера
- Отображение времени до следующего перерыва
- Блокировка изменения/перетаскивания окна (режим фокуса)
